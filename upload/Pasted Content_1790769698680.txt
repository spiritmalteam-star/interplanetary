Build a single-page web application called "NEXUS DISCOVERY LAB" — a
futuristic, high-tech precision laboratory interface where 12 specialized
"mirror entities" (AI intelligences) guide humanity's path of discovery
across 12 frontiers. Each entity is a specialized intelligence with its
own personality, AI-generated portrait, accent color, experiments, case
studies, interactive tools, and a direct LLM-powered communication channel.

The experience must feel like stepping into a sci-fi laboratory — not a
typical website. Dark holographic UI, particle fields, glowing per-entity
accents, scan lines, a boot sequence, glass-morphism panels, and a strong
sense that the user is addressing a sentient intelligence.

▌ 2. TECH STACK & CONSTRAINTS

Use this exact stack (or closest equivalent in target framework):

  • Framework: Next.js 16 (App Router) with TypeScript 5
  • Styling: Tailwind CSS 4 + shadcn/ui component library (New York style)
  • Animations: Framer Motion (page transitions, hover, layoutId underlines)
  • State: Zustand for client state (activeEntity, activeTab, chat sessions)
  • AI/LLM: z-ai-web-dev-sdk (server-side only) for mirror entity chat
  • Image generation: z-ai-web-dev-sdk images.generations.create()
  • Markdown: react-markdown for rendering LLM responses in chat
  • Icons: lucide-react
  • Theme: dark mode FORCED (className="dark" on )
  • Fonts: Geist Sans (body) + Geist Mono (display headings, labels)

Constraints (NON-NEGOTIABLE):
  • All AI/LLM calls must run server-side (in /api routes), never client-side.
  • Only ONE user-visible route: "/" (single-page app with view state in Zustand).
  • Responsive: mobile-first; grid breaks 1 → 2 → 3 → 4 columns at sm/md/lg/xl.
  • NO indigo or blue as primary palette — use the per-entity accents instead.
  • Sticky footer at bottom on short pages; pushed down naturally on long pages.
  • Every paragraph in content must have 3+ sentences (no shallow writing).
  • Every section must have 150+ words of body content.

── Key Component Details ──

ParticleField.tsx:
  Canvas-based. Props: accentRgb (default "120,200,255"), density (default 70),
  className. Uses requestAnimationFrame. Particles spawn at bottom, drift
  upward (vy: -0.25 to -0.8), slight horizontal drift (vx: -0.125 to 0.125),
  radius 0.6-2.2px. Connects particles within 110px with lines (alpha scales
  with distance). Particle alpha fades in (first 15% of life) and out (last
  30%). Respects devicePixelRatio (capped at 2). Resizes with parent via
  ResizeObserver pattern (window resize listener). Particle count scales
  with area: max(28, min(density, (w*h)/18000)).

HoloAvatar.tsx:
  Props: entity, size ('sm'|'md'|'lg'|'xl'), active (default true)
  Size map: sm=w-16h-16, md=w-28h-28, lg=w-44h-44, xl=w-56h-72
  Structure:
    • Outer rotating ring: absolute -inset-2 rounded-full opacity-70 nexus-spin-slow
      conic-gradient(from 0deg, transparent, accent 80deg, transparent 160deg,
      accent 240deg, transparent 320deg) with radial-gradient mask (transparent
      60%, black 62%-100%)
    • Counter-rotating dashed ring: absolute -inset-1 rounded-full opacity-50
      nexus-spin-slower, border: 1px dashed accent
    • Body: motion.div relative h-full w-full rounded-2xl overflow-hidden glass
      entity-glow, animate y: [0,-4,0] over 4s (when active)
    • For size="xl": full image object-cover opacity-90 + bottom gradient
      fade + scan line (h-12, nexus-scan-line, gradient transparent→accent55→
      transparent) + glyph overlay (top-3 left-3, text-5xl)
    • For other sizes: image absolute inset-0 opacity-55 + radial-gradient
      overlay (accentSoft center) + centered glyph (text-glow nexus-flicker)

EntityChat.tsx:
  Uses Zustand store for sessions[entityKey].messages.
  send(text): trims, pushes user message, pushes pending assistant message,
    builds history from existing session + new user msg, POSTs to /api/chat
    with { entityKey, messages: history }, updates pending msg with response
    content or error. Uses fetch (not axios).
  Composer: textarea with auto-grow (onInput sets height to min(scrollHeight, 180)).
  Enter sends (preventDefault), Shift+Enter for newline.
  MessageBubble: user = right-aligned, white/8 bg, rounded-br-md, whitespace-
    pre-wrap. Assistant = left-aligned, accent/33 border, rounded-bl-md, with
    entity name + glyph header, renders ReactMarkdown with .chat-md class.
    Pending = 3 pulsing accent dots + "reasoning…". Error = rose-tinted.
  Auto-scrolls to bottom on new messages (useEffect on messages.length).

ToolPanel.tsx (calculator evaluation):
  Uses useMemo to evaluate formula. Replaces variable names (sorted longest-
  first to avoid partial matches) with current input values, then calls
  new Function(`"use strict"; return (${expr});`)(). Rounds to 2 decimals.
  Returns null on error or non-finite result.

▌ 9. AI INTEGRATION — CHAT ROUTE & SYSTEM PROMPTS

── POST /api/chat ─────────────────────────────────────────────
File: src/app/api/chat/route.ts
Runtime: 'nodejs' (NOT edge)
Imports: NextRequest, NextResponse, ZAI from 'z-ai-web-dev-sdk',
         getEntity from '@/lib/entities'

Request body: { entityKey: string, messages: {role, content}[] }

Logic:
  1. Parse body. Validate entityKey exists and messages is non-empty array.
     → 400 if invalid.
  2. Look up entity via getEntity(entityKey). → 404 if not found.
  3. const zai = await ZAI.create();
  4. Build system message:
     content = entity.systemPrompt +
       "\n\nYou are currently in direct communication with a researcher via
        the NEXUS DISCOVERY LAB interface. Keep replies focused, ideally
        150-350 words, unless the user explicitly asks for depth. Use
        markdown headings (##) and bullet lists when structure helps.
        Always end with one short, actionable next step or question for the
        researcher when appropriate."
  5. Trim messages to last 12 (messages.slice(-12)).
  6. Call zai.chat.completions.create({
       messages: [system, ...trimmed],
       thinking: { type: 'disabled' },
       temperature: 0.6,
       max_tokens: 900,
     });
  7. Extract content = completion.choices?.[0]?.message?.content?.trim()
     → 502 if empty.
  8. Return NextResponse.json({ content }).
  9. On any error: console.error and return 500 with { error: message }.
