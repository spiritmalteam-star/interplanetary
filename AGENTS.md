# AGENTS.md — read this first

All coding agents (Claude, Z.ai, or any future session) working on ReflectMe MUST read and follow the
permanent protocol and shared coordination documents in **`.coordination/`**:

- `.coordination/AGENTS.md` — the permanent multi-agent development protocol (identity, law, verification, integration).
- `.coordination/CURRENT_STATE.md` — commits, environments, active architecture, known limitations.
- `.coordination/TASK_REGISTRY.md` — claim a task before you overlap another intelligence.
- `.coordination/DEVELOPMENT_LOG.md` — chronological record of significant changes and decisions.
- `.coordination/ARCHITECTURE.md` — services, APIs, data models, component relationships.
- `.coordination/HANDOFF.md` — continue from here without guessing or repeating work.
- `.coordination/KNOWN_ISSUES.md` — confirmed bugs vs assumptions.
- `.coordination/DESIGN_SYSTEM.md` — the authoritative visual language.
- `.coordination/RELEASE_CHECKLIST.md` — mandatory validation before any production push.

Golden rules: fetch before you start; preserve uncommitted work; never force-push `main`; never leave
conflict markers; never claim unverified results; leave a handoff. Evolution without regression.
